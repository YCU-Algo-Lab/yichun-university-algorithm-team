基础算法

先把复杂度意识建立起来：同样的结果，不同写法的代价可能相差几个数量级。基础阶段的重点是枚举、排序与二分这些“每天都在用”的工具。

复杂度分析排序二分查找 双指针前缀和贪心

典型复杂度：二分查找 O(log n) · 排序 O(n log n) · 前缀和查询 O(1)

数据结构

把“维护什么、查询什么”想清楚，数据结构自然就选出来了。重点是并查集、堆、线段树与树状数组这几类高频结构。

栈与队列并查集堆 线段树树状数组单调队列

典型复杂度：并查集近似 O(α(n)) · 线段树单点更新与区间查询 O(log n)

图论

从建图开始，到最短路、最小生成树与拓扑排序，再到二分图匹配和网络流。图论题的关键往往在于问题怎么抽象成图。

最短路最小生成树拓扑排序 二分图匹配网络流

典型复杂度：Dijkstra（堆优化）O((n+m) log n) · Kruskal O(m log m)

动态规划

DP 的核心是定义好状态和转移。训练从线性 DP 与背包入手，逐步过渡到区间、树形与状态压缩 DP。

线性 DP背包区间 DP 树形 DP状态压缩数位 DP

典型复杂度：0/1 背包 O(n·V) · 状压 DP O(2ⁿ·n)

数学

数论与组合计数是竞赛高频考点，配合快速幂与逆元处理取模运算，也要能应付概率期望与简单博弈问题。

质数与筛法同余与逆元快速幂 组合计数概率与期望博弈论

典型复杂度：埃氏筛 O(n log log n) · 快速幂 O(log n)

字符串

从模式匹配到多模式匹配，字符串题讲究实现细节与边界处理。KMP、字符串哈希与 Trie 是入门必掌握的三件工具。

KMP字符串哈希Trie Z 函数后缀数组AC 自动机

典型复杂度：KMP 匹配 O(n+m) · 字符串哈希比较 O(1)

加入我们

不需要你现在就很强，只需要你愿意练。

算法队欢迎任何年级、任何专业、对编程和算法有兴趣的同学。零基础可以从入门班开始，基础较好的同学可以直接参加选拔。

  • 面向全校：宜春学院在校本科生均可报名，不限专业与年级。
  • 分级培养：入门、进阶、竞赛三级训练，按当前水平进入合适的阶段。
  • 老队员带练：高年级队员负责讲题、带节奏、答疑，遇到瓶颈有人可问。
  • 真实赛场：表现突出的队员将有机会代表学校参加各级程序设计竞赛。

报名方式

留意学院与班级发布的招新通知；选拔赛开始前，我们会通过校内渠道公布时间与场次安排。

常见问题

关于算法队，你可能想问。

完全零基础可以加入吗？

可以。算法队设有入门班，从 C++ 语法与复杂度讲起，只要愿意投入时间，零基础也能跟上训练节奏。

需要什么语言基础？

竞赛以 C++ 为主，训练与讲题基本围绕 C++17 展开；如果你更熟悉 Python，也可以用它入门，后续再逐步过渡。

训练会占用多少时间？

常规安排是每周固定一次集中训练，加上课后的题单练习与线上周赛。投入越多，进步越快，但不会强制占用上课时间。

没有竞赛经历，能参加区域赛吗？

可以先从校内选拔赛和校内程序设计竞赛起步，随着解题能力提升，再通过选拔加入区域赛队伍。路径是一步一步走出来的。

加入后有什么要求？

按时参加训练、完成阶段题单、参加模拟赛并认真复盘。保持稳定的节奏，比偶尔的高强度突击更有效。
